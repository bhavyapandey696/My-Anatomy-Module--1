# COVID-19 Module 1 – India Data Analysis

A Python-based exploratory data analysis project on COVID-19 cases in India using Google Colab.

## 📌 Project Overview

This project analyzes COVID-19 data to understand the impact of the pandemic across Indian states and union territories.

### 🔍 Analysis Performed
- Dataset exploration and structure
- Data types and missing values
- Top 10 states by confirmed cases
- Top 10 states by deaths
- Top 10 states by cured cases
- Data visualization using bar charts

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
- KaggleHub

## 📊 Dataset

**COVID-19 in India** dataset from Kaggle.

Main file used:
`covid_19_india.csv`

The dataset contains **18,110 records and 9 columns** covering COVID-19 data from **2020–2021**.
